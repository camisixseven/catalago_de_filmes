## Requisitos funcionais

-   **RF01 - autenticação de usuário:** O sistema deve permitir que o usuário faça login informando seu usuário e senha para acessar o sistema.
    
-   **RF02 - cadastrar filme:** O sistema deve permitir o cadastro de um novo filme com os seguintes dados:
    
    -   Título
        
    -   Ano de lançamento
        
    -   Gênero
        
    -   Nota (de 0 a 10)
        
    -   Upload/Envio da imagem da capa do filme (pôster)
        
-   **RF03 - visualizar  coleção:** O sistema deve exibir os filmes cadastrados em formato de galeria visual (com as capas destacadas).
    
-   **RF04 - editar filme:** O sistema deve permitir alterar as informações de um filme já cadastrado (incluindo a nota e os demais dados).
    
-   **RF05 - excluir filme:** O sistema deve permitir a remoção de um filme cadastrado da lista/banco de dados.
    

##  Requisitos Não Funcionais (RNF)

São os critérios de qualidade, restrições e características técnicas do sistema:

-   **RNF01 - segurança:** O acesso deve ser restrito e privado. Apenas o usuário autenticado pode visualizar ou alterar os dados da sua coleção.
    
-   **RNF02 - interface :** A interface deve ser focada em uma exibição visual atraente (layout em estante/galeria de pôsteres).
    
-   **RNF03 - armazenamento de arquivos:** O sistema deve ser capaz de receber, processar e armazenar arquivos de imagem (capas dos filmes).
